概要

レトロゲーム風シミュレーションゲーム『Kaleido Trigger（カレトリ）』 ――基本、生命を置いて眺めるゲーム。ウィルスの波状攻撃をしのぐと１面クリア。

本日のアクセス数：1　　トータルアクセス数：1070

起動方法

  • ダウンロードしたプロジェクトの「MAIN.PRG」を実行してください。

ゲームの説明

画面説明

  • カーソル（黄色）：生命体を置く位置や、進化対象の生命体を指定する
  • セレクタ（水色）：配置する生命種や、進化交配対象の生命体を選択する
  • パレット（画面下部）：配置・交配可能な生命種の一覧
  • ステータス（画面左側）：セレクタが選択している生命種のクラス、属性(RGB)、体力(HP)、免疫力(IMM)を表示。 クラスは「VIRUS（ウィルス）・BOTANI（植物級）・HERBI（草食級）・CARNI（肉食級）」のいずれか。 進化中はカーソルが捕まえた生命体のステータスを画面右側に表示する。
  • スコア（画面右上）：消費したエネルギーの合計値
  • エネルギー（画面右）：残存エネルギー。生命体を配置するときにはエネルギーが必要。
  • 個体数（画面右上灰色）：ウィルス・植物級・草食級・肉食級の個体数
  • 時間（画面右下）：ウィルス波状攻撃(WAVE)残り時間。この時間が0になると波状攻撃が止み、 勝利条件・敗北条件のチェックが始まる（敵ウィルスか自生命体か、どちらかが絶滅するまで）。

操作方法

  • 左JOY-CON スティック： 　カーソルを移動する
  • 左JOY-CON 左右ボタン： 　生命パレットから生命種を選択する
  • 右JOY-CON Ａボタン： 　カーソルに選択中の生命種を置く。生命種によって、相応のエネルギーが必要。
  • 右JOY-CON Ｂボタン： 　長押しで、カーソルで捕まえた生命体と、選択中の生命種を交配して、新しい生命種を創る。 　生命を誕生させるには、生命種によって、相応のエネルギーが必要。
  • 右JOY-CON Ｘボタン： 　選択中の生命種を削除し、エリア上の全ての生命体を消滅させる。
  • Ｌ／Ｒボタン： 　エリア表示の縮小／拡大
  • 左JOY-CON 上ボタン： 　生命パレットをウィルス級→植物級→草食級→肉食級の順にソートする。
  • 右JOY-CON Ｙボタン： 　ギブアップ。勝利条件・敗北条件判定中（TIME=0）の時に押すと強制的に GAME OVER。

生命種の説明

  • VIRUS：ウィルス級　（近くの生命体を探して寄生する。）
  • BOTANI：植物級　（一定時間ごとに複製を作り繁殖する。）
  • HERBI：草食級　（植物級を捕食して増殖する。繁殖力が強い。）
  • CARNI：肉食級　（草食級を捕食して増殖する。ウィルスへの免疫力が高い。）

属性の説明

  • 赤＞緑＞青＞赤の順に強い。
  • 赤属性（炎）は緑属性（緑）を焼くので強い。
  • 緑属性（緑）は青属性（水）を吸うので強い。
  • 青属性（水）は赤属性（炎）を消すので強い。
  • 100%赤属性の生命体は、100%青属性の生命体にダメージを与えることができない。

勝利条件

  • 全てのウィルスを撃破する。

敗北条件

  • 全ての生命体（植物級・草食級・肉食級）が消滅する。

エネルギー

  • 生命体を置くと減る。
  • 生命体が増殖すると増える。

進化の説明

  • カーソルで【ウィルス】を捕まえている時
    • パレットで【ウィルス】を選択している　→　【ウィルス】を生成
    • パレットで【植物級】を選択している　→　【植物級】に進化
    • パレットで【草食級】を選択している　→　【植物級】に進化
    • パレットで【肉食級】を選択している　→　【植物級】に進化
  • カーソルで【植物級】を捕まえている時
    • パレットで【ウィルス】を選択している　→　【草食級】に進化
    • パレットで【植物級】を選択している　→　【草食級】に進化
    • パレットで【草食級】を選択している　→　【植物級】を生成
    • パレットで【肉食級】を選択している　→　【植物級】を生成
  • カーソルで【草食級】を捕まえている時
    • パレットで【ウィルス】を選択している　→　【肉食級】に進化
    • パレットで【植物級】を選択している　→　【肉食級】に進化
    • パレットで【草食級】を選択している　→　【肉食級】に進化
    • パレットで【肉食級】を選択している　→　【草食級】を生成
  • カーソルで【肉食級】を捕まえている時
    • パレットで【ウィルス】を選択している　→　【草食級】に退化
    • パレットで【植物級】を選択している　→　【草食級】に退化
    • パレットで【草食級】を選択している　→　【草食級】に退化
    • パレットで【肉食級】を選択している　→　【肉食級】を生成
  • 体力（HP）や免疫力（IMM）は、進化によって増えるので、 あえて肉食級を草食級に退化させたり、そこから肉食級を作り直すことで、強い生命種を創造できる。

余談

  • 本ゲームは、「ライフゲーム」をベースにしています。 基本的に、カーソルに生命を置いて、あとは変化を眺めるだけのゲームですが、 時々「START WAVE」の表示と共にウィルスの包囲攻撃が始まり、タイマーがカウントダウンします。 タイマーがゼロになってから【勝利条件】【敗北条件】の判定期間に入ります。
  • 草食級を広々と放置していると、後半面の強いウィルスの養殖場になってしまい、 あっというまに生態系を殲滅させてしまうので、ある程度の免疫力（IMM）のある 草食級か肉食級を配置するようにしてください。
  • 肉食級を早くから配置し過ぎると、草食級を食べつくして自滅します。
  • 体力の大きなライフ種は、自己複製（出産）のために多くの捕食が必要になります。 体力の小さなライフ種で増殖力を確保しウィルスに対するバリアを作るのも一つの手です。
  • 植物級は、赤＞緑＞青＞赤　の力関係にあることを覚えておき、 赤が緑を、緑が青を、青が赤を追いかけるような配置にして増殖させると、 安定して３属性が維持され、生態系の多様性を維持しやすくなります。
  • ウィルスの表現は、「スピログラフ」を参考にしています。
  • 動物（草食級・肉食級）の表現は、「万華鏡（カレイドスコープ）」を参考にしています。
  • 背景の表現には、「パーリンノイズ」に、プチコン4の強力なレイヤーフィルタ表現機能の一つである 「水平ラスター変形」を使用しています。
  • BGMは、植物級が増えるとパーカッションの音量が増える、肉食級が増えるとベースが大きくなる、など、 個体数に応じて各パートの音量が変わります。 SE（効果音）の幾つかは、画面上のどこで発生しているかによって ステレオの定位（パンポット）も変えています。
  • 画面左上の「PERFORMANCE」は、メインループ１回の処理時間（1/10000秒単位）です。 　この値が、だいたい 160 に収まっていれば、VSYNC（秒間60フレーム）で滑らかに動きます。
