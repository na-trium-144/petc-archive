概要

EASY GAME(子供向けゲーム)の３つ目です。

タッチパネルのみで描画できる簡単操作のお絵かきプログラムです。

アイコンの数の関係で機能が少ないですが、

GRPEDと違ってペンのサイズを変えても滑らかな線を描けるようにしてあります。

画面の説明　

左上のパレット　　→　タッチでカラーを選択します。

左の５つのアイコン　→　上から順に　ペン1x1,ペン2x2,ペン4x4,塗りつぶし,全消し　です。

　　　大きな枠　　　→　描画可能範囲です。

　　右上の×印　　　→　END

セーブ・ロード機能について

このプログラムは子供用のらくがきツールとして作ったので、セーブ機能はいらないかなと思いました。

でも一応作っておきました。

STARTボタンで上画面にメニューがでます。

　ロード　→　X

　セーブ　→　Y

　もどる　→　START

対応するボタンを押してファイル名を入力すればOKです。枠の中の絵だけ保存されます。

他のツール等で作った絵をロードしてもよいですが、枠外の部分は消されます。
