2020年3月12日投稿 / 投稿者 : takumi / タグ : 投稿プログラム MML Spectacmine GAMES.

概要

MMLの歌詞をカラオケ風に順次更新していく音楽プレーヤーです。
再生にはこのプレーヤーとLYRIC BGM DATAという独自フォーマットファイルが必要です。
Musics等に内蔵されているBHDやExMML等のファイルは読み込みません。

  • Ver.2.0でNNMも読み込むようになりました。
    • (当初の告知と異なり)歌詞表示はされません。

LYRIC BGM DATAについて

Ver.1.0の場合
  1. ＠ＬＹＢ
  2. ＤＡＴＡ　”１．０”
  3. ＤＡＴＡ　”色は匂へど散りぬるを”
  4. ＤＡＴＡ　”幽閉サテライト”
  5. ＤＡＴＡ　”Ｃ”
  6. ＤＡＴＡ　”Ｔ１３８：０［＠８８Ｖ９３，Ａ８＜Ｃ８Ｄ２．．．”
  7. ＤＡＴＡ　”＜０６＞色は匂へど　散りぬるを”
  8. ＤＡＴＡ　”＜１０＞さ迷う事さえ　許せなかった．．．”
  10. 省略
  12. ＤＡＴＡ　”＜０８＞悪夢が優しく私を弄ぶ
  13. ＤＡＴＡ　”０”
  • DATA "1.0"
    • LYBのversion表記です。
  • DATA "色は匂へど散りぬるを"
    • タイトル名表示です。
  • DATA "幽閉サテライト"
    • 作曲者名表示です。
  • DATA "C"
    • ジャンル識別文字列です。
      • Aがポップス、Bが東方Project、Cが東方Project二次作品、Dがバラエティ、Eがクラシックを表します。
  • DATA "<06>色は匂へど　散りぬるを"　以降
    • 歌詞の表示です。
    • 初めの<>内の数値分歌詞を表示します。
      • 数値1に対して1秒です。

  • <>内の数値の桁数制限がなくなりました。
  • また、@DATA文の後にDATA"{単語=要素又は値}"を記述することで様々な指定ができるようになりました。
    • LYB Player Ver.3.0で指定できる内容は現在{DATE=}と{TEXT=}のみです。
    • LYB Player Ver.4.0で指定できる内容に{VER=}を追加しました。

LYRIC BGM DATA の更新情報

  • V1.0
    • 完成。
  • V2.0
    • <>内の数値を3桁に変更(V1.0のLYBをV2.0に対応させるには<>内の数値の先頭に0を付ける必要がある)。
    • 歌詞のデータの後に元曲制作者の指定が可能(強制)。
  • V3.0
    • <>内の桁数制限を無効化。
    • NNMのライブラリを利用し@DATA以降のメタデータの記述が可能。
  • V4.0
    • ジャンル表記にアルファベット以外を記述するとその単語のまま表示させるように変更。
